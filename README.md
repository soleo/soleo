#### 🚀 What I'm building on my own

| Project | What it is |
| --- | --- |
| 🛒 **[GroceryTrack](https://grocerytrack.food)** | My first solo product, built from zero. It reads grocery receipt photos with AI, then tracks items, prices and spending over time. I built the apps, web, backend, data jobs and infrastructure myself. |
| 🎬 **[Tinycap](https://github.com/soleo/tinycap)** | A small, native macOS menu-bar screen recorder and screenshot tool. It records a window, screen, area or connected iPhone to MP4/WebM/GIF, and it's private by default. I built it while making GroceryTrack. `brew install --cask soleo/tap/tinycap` |
| 👻 **[bogyman](https://github.com/soleo/bogyman-cli)** | A CLI that tells you which of your Claude Code and Codex agent sessions needs you, on what, and for how long. I built it while working with AI agents on GroceryTrack. `brew install soleo/tap/bogyman` |
| 📟 **[Habibi](https://heyhabibi.io/)** *(in progress)* | A fun hardware project: a retro, pager-style handheld for group voting. Use it for yes/no calls, rating a film screening or scrum poker, in groups from 4 people to a 300-seat theater. It has an e-ink screen, five rubber keys and a bright yellow 3D-printed case. Handsets send votes wirelessly over ESP-NOW (ESP32-C6) to a Raspberry Pi hub. |

Both dev tools came from problems I hit while building a product on my own. When I hit a tool gap, I build the tool ([why I built Tinycap and bogyman →](https://xinjiangshao.com/blog/2026-10-29-bogyman-and-tinycap)). Now I'm taking the same zero-to-one approach to hardware.
